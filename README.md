# RedAuto 小红书内容工作台

**围绕内容运营流程，探索从选题到复盘的本地工作台。**

## 项目简介

将选题收集、信息核查、AI 辅助起草、配图、人工审核、发布与复盘组织为可追踪的内容流程，降低内容生产中反复切换工具和管理素材的成本。

## 展示内容

- 围绕内容生产设计分阶段工作流程。
- 将 AI 辅助创作与人工核查、审核结合。
- 用项目展示页说明场景、功能与实现边界。

本仓库是静态项目案例展示，不包含完整工作台代码、账号数据或凭证。项目基于 [Beav](https://github.com/Jamailar/Beav) 进行学习与改造，并使用其他第三方工具；相关来源和边界见展示页，各第三方项目适用其许可证。
